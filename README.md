# HACK1
HACK1: AI Web App Hackathon
Date: November 19, 2026
Teams: Same as Project 2

Objective
Brainstorm 5 original ideas, select one, and build a functional web application using AI-assisted development tools.

Ideas must be new and cannot have been pitched previously by your team or another team.

Submission Requirements
One submission per team on Canvas containing:

Five Ideas: List and briefly describe your five ideas. Clearly identify the selected idea.

GitHub URL: Link to your application's source code.

Live App URL: Link to your deployed, working application (Netlify, GitHub Pages, etc.).

AI Usage (model & prompt): Briefly explain which AI tools you used and add your prompt.

Important Notes
Your app must have at least one working interactive feature.

Customize the design—don't simply accept AI-generated default styles.

All team members must contribute.

Ensure your application is accessible to judges.

Extra Credit: The top-ranked application receives 3 points out of 100 toward the course grade for each team member.
